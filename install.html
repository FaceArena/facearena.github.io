Добавьте на экран «Домой»

Для удобства: FACE ARENA откроется в один тап, как приложение, без адресной строки.

  1. Откройте сайт в SafariИз мессенджеров кнопки может не быть: выберите «Открыть в Safari».
  2. Нажмите «Поделиться»Значок внизу экрана (на iPad — вверху).
  3. Выберите «На экран “Домой”»Пролистайте список действий вниз. Значок
  4. Нажмите «Добавить»Кнопка находится в правом верхнем углу. Иконка FACE ARENA появится на экране «Домой».
  1. Откройте сайт в ChromeЕсли сайт открыт в другом браузере, шаги могут отличаться.
  2. Откройте менюНажмите три точки справа от адресной строки.
  3. Выберите «Установить приложение»Если такого пункта нет, выберите «Добавить на главный экран».
  4. Подтвердите установкуНажмите «Установить» или «Добавить».
